# Robo-Knowledge

مخزن دانش و منابع قابل‌بازیابی دستیار هوشمند «روبو» برای سامانه آموزشی مدار.

## نقش این مخزن
این مخزن محل نگهداری منابع آموزشیِ مجاز، راهنماها، فراداده و قراردادهای محتوایی است. این مخزن به‌تنهایی موتور اجرای عامل نیست و نباید جایگزین پایگاه داده عملیاتی مدار شود.

## اصول پایه
- محتوای عمومی و مجاز؛ بدون اطلاعات شخصی دانش‌آموزان یا اسرار فنی.
- هر سند باید منبع، موضوع، سطح آموزشی، زبان و تاریخ بازبینی داشته باشد.
- پاسخ‌های مبتنی بر دانش باید تا حد امکان به سند منبع ارجاع دهند.
- داده‌های زنده و شخصی از APIهای احراز هویت‌شده مدار دریافت می‌شوند، نه از این مخزن.
- هیچ فایل env، کلید API، توکن یا رمز عبوری در Git ثبت نشود.

## ساختار
- `knowledge/`: منابع آموزشی و راهنماهای تأییدشده
- `schemas/`: قراردادهای ساختاری اسناد
- `docs/`: معماری، امنیت و فرایند نگهداری دانش

## وضعیت
مرحلهٔ اول: معماری پایه و کتابخانهٔ آغازین مشاوره/مهارت‌های مطالعه آماده شده است. اتصال به موتور بازیابی (RAG)، ایندکس‌گذاری و عامل اجرایی هنوز باید در بک‌اند انجام شود.

## زبان و قالب
اسناد می‌توانند فارسی یا انگلیسی باشند. برای منابع متنی جدید از Markdown و فرادادهٔ YAML در ابتدای فایل استفاده کنید.
