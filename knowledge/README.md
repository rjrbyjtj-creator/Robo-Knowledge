# کتابخانهٔ دانش روبو

این پوشه منبع دانش آموزشی و مشاوره‌ای روبو است. اسناد با فرادادهٔ YAML نگهداری می‌شوند تا قطعه‌بندی، ایندکس‌گذاری و بازیابی آن‌ها قابل اتوماسیون باشد.

## حوزه‌های آماده
- `advising/`: مشاوره، نیازسنجی، هدف‌گذاری و مسیر تحصیلی
- `study-skills/`: روش‌های یادگیری، حافظه، مرور و برنامه‌ریزی
- `assessment/`: آمادگی آزمون و تحلیل خطا
- `tutoring/`: روش تدریس، توضیح مرحله‌ای و رفع اشکال
- `wellbeing/`: حمایت آموزشی و مرزبندی ارجاع به انسان متخصص

## اصول استفاده
- فقط منابع با وضعیت `reviewed` برای پاسخ مستند و قطعی مناسب‌اند.
- منابع با وضعیت `draft` باید با احتیاط استفاده شوند یا تا زمان بازبینی کنار گذاشته شوند.
- کتاب‌ها و محتوای صفحه‌به‌صفحه در پوشهٔ جداگانهٔ `../textbooks/` مدیریت می‌شوند.
- پاسخ مبتنی بر کتاب باید نام کتاب، فصل و شمارهٔ صفحه را تا حد امکان نمایش دهد.
- دانش تکمیلی روبو باید از متن دقیق کتاب تفکیک شود.
- نقشهٔ همهٔ حوزه‌ها در `../docs/knowledge-library-map.md` قرار دارد.
