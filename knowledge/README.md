# منابع دانش

منابع آموزشی تأییدشده در این پوشه و زیرپوشه‌های موضوعی نگهداری می‌شوند.

پیشنهاد ساختار:
- `knowledge/math/`
- `knowledge/science/`
- `knowledge/literature/`
- `knowledge/languages/`
- `knowledge/study-skills/`

هر فایل باید از قالب تعریف‌شده در `docs/knowledge-format.md` پیروی کند. تا زمان بررسی صحت، منبع و مجوز، وضعیت سند را `draft` نگه دارید.
