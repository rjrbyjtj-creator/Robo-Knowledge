# کتابخانهٔ کتاب‌های درسی

این پوشه برای ورود محتوای متنی کتاب‌ها و منابع درسی به پایگاه دانش روبو آماده شده است.

## مهم: وضعیت مخزن
مخزن فعلی GitHub عمومی است. متن کامل کتاب‌های دارای حق نشر را تا زمانی که مجازبودن انتشارشان روشن نشده یا مخزن خصوصی نشده، در این مخزن عمومی بارگذاری نکنید. خصوصی‌کردن مخزن نیز به‌تنهایی مجوز نشر یا پردازش یک اثر را ایجاد نمی‌کند؛ حق استفاده و دسترسی باید رعایت شود.

برای کتاب‌هایی که مجوز انتشار ندارند، مسیر مناسب می‌تواند ذخیره‌سازی خصوصی در فضای امن یا پایگاه دادهٔ کنترل‌شده باشد و Git فقط کد و فرادادهٔ غیرحساس را نگه دارد.

## بستهٔ ورودی ZIP
وقتی فایل ZIP را ارسال کردی، ابتدا ساختار و محتویات آن را فهرست و اعتبارسنجی می‌کنیم؛ سپس هر کتاب را جداگانه پردازش می‌کنیم. انتظار پیشنهادی:
```
textbooks.zip
  manifest.csv
  math/
    grade-07/
      book.md
      pages/
        page-001.md
        page-002.md
  science/
    grade-07/
      book.md
      pages/
        page-001.md
```

## الزامات حفظ وفاداری به کتاب
- نام دقیق کتاب، پایه، رشته، سال/ویرایش و ناشر حفظ شود.
- متن هر صفحه به ترتیب اصلی نگه داشته شود.
- شمارهٔ چاپی صفحه از شمارهٔ صفحهٔ PDF جدا ثبت شود.
- عنوان‌ها، زیرعنوان‌ها، مثال‌ها، تمرین‌ها، جدول‌ها، فرمول‌ها، زیرنویس شکل‌ها و پاورقی‌ها حذف نشوند.
- جدول و فرمول تا جای ممکن ساختارمند و قابل‌بازیابی باشند.
- متن خام استخراج‌شده حفظ شود؛ اصلاح تایپی یا نرمال‌سازی فقط در فیلد جداگانه انجام شود.
- هر صفحه به منبع و شناسهٔ یکتا متصل باشد.
- بخش ناخوانا یا نامطمئن با نشانگر مشخص شود؛ روبو نباید آن را حدس بزند.
- ترتیب بلوک‌های صفحه باید قابل بازسازی باشد.

## فرایند ورود
1. فهرست ZIP و فایل‌ها بررسی می‌شود.
2. کتاب‌ها از هم تفکیک و فرادادهٔ هر کتاب شناسایی می‌شود.
3. صفحه‌ها، ترتیب متن و عناصر ساختاری استخراج می‌شوند.
4. نمونه‌ای از صفحه‌ها با فایل اصلی مقابله می‌شود.
5. خطاهای OCR یا تبدیل، مخصوصاً فرمول‌ها، جدول‌ها و فارسی، اصلاح می‌شوند.
6. صفحه‌ها به قطعه‌های قابل‌بازیابی تقسیم می‌شوند، اما پیوند به صفحهٔ اصلی حفظ می‌شود.
7. ایندکس جست‌وجو ساخته می‌شود.
8. پاسخ روبو با ارجاع دقیق به کتاب، فصل و صفحه ارائه می‌شود.

## نکته
وجود متن یک کتاب در مخزن دانش به معنی آموزش مجدد مدل پایه نیست. این داده‌ها برای بازیابی هنگام پاسخ‌گویی (RAG) استفاده می‌شوند تا روبو بتواند به محتوای مشخص کتاب رجوع کند.
